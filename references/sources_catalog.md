# 全信源清单（消息去伪存真）

本 skill 把实际落地的多信源查证机制整理成统一目录。信源分两类：

- **机制 A（Python/Shell 内可调用）**：脚本直接 subprocess / HTTP 调用，确定性、可复用。
- **机制 B（Agent 会话内调用）**：由 Agent 在会话内触发（WebSearch / WebFetch / 技能），流程只消费其产物。

## 微信公众号官方号层（第三后端 weixin）

**背景**：大量平台规则/消费报告的**原始出处**是微信公众号文章（如抖音生活服务《2026中秋国庆消费报告》），搜索引擎收录差，公开检索只能拿到媒体转载——而各转载版本内容常有出入（实录：豆包销售额环比+71% 仅上证报版有，人民网版无）。

**A 类官方公众号清单**（平台规则/官方报告优先在此回溯原文）：

| 公众号 | 主体 | 覆盖内容 |
|---|---|---|
| 抖音生活服务学习中心 | 抖音 | 商家规则、费率政策、消费报告 |
| 抖音来客 | 抖音 | 商家产品说明、结算规则 |
| 豆包 | 字节跳动 | AI 产品动态 |
| 微信公开课 / 微信派 | 腾讯 | 微信生态官方发布 |

**定级规则**：公众号原文 > 权威媒体转载 > 自媒体转述。仅有转载时必须标注「未回溯原文」；≥2 家转载内容不一致时，必须触发原文回溯（走 weixin 通道）。

**调用链与失败降级**：

```
sh $SKILL/scripts/weixin_search.sh "<query>"     # 主通道：搜狗微信搜索（免登录）
  exit 0 → 有结果（标题+公众号名+日期+链接）
  exit 2 → 无结果（不代表命题为假）
  exit 3 → 搜狗反爬拦截 → 如实标注「⚠️ 公众号通道未完成」，不编造、不阻断主流程
  exit 4 → 网络失败
```

搜狗返回的 `/link?url=...` 为跳转链接，正文可在会话内 WebFetch 该链接取得（或提示用户在微信内打开）。

## 信源总表

| 信源 | 类别 | 调用方式（具体） | 失败降级行为 | 优先级 |
|---|---|---|---|---|
| 腾讯较真 CLI（jiaozhen） | A | `sh $SKILL/scripts/jiaozhen_cli.sh --query "<claim>"` | 标签"⚠️第三源未完成"，不阻断 | 中文查证高 |
| WebCite API | A | `sh $SKILL/scripts/webcite_cli.sh "<claim>"` | Key 缺失 exit=2 干净报错；429 标注额度耗尽 | 国际源高 |
| 搜狗微信搜索（weixin） | A | `sh $SKILL/scripts/weixin_search.sh "<query>"` | 反爬拦截 → 标注「公众号通道未完成」 | 原文回溯高 |
| 会话内 WebSearch / WebFetch | B | Agent 直接调用，读官方站点与权威媒体原文 | 结果须再过双源规则 | 通用高 |
| 技能 `news-search` | B | Agent 会话内触发 | 降级到 tencent-news | 新闻中 |
| 技能 `tencent-news` | B | Agent 会话内触发 | 降级 | 新闻低 |

## 来源黑名单（整体剔除）

- 媒体二手转载号 / 快讯号 / 播报类账号：无一手信源，内容多为拼接。
- 无法确认原始出处的社交截图：必须先回溯原文再评估。

## 失败降级总原则

- 任何单源失败 → **降级标记**而非报错退出（沿用 `_degraded` / `⚠️扫描未完成` / 较真超时逻辑）。
- 事件扫描依赖 Agent 跑 WebSearch 后方可填值；未扫描 → `geopolitical` 字段留空，报告加载器标"⚠️ 事件扫描未完成"。
- 输出 JSON 的 `meta.reliability` 按 `sources_used` 数量启发式评级：≥3 源=高，2 源=中，<2 源=低。
- **绝不回退 WebSearch 编造**：查不到就是查不到，标注比编造可靠。
