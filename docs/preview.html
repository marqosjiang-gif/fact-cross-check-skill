01 · CHANNELS

四通道查证，自动调度

中文命题走较真主源；英文命题走 WebCite；命中「报告 / 政策 / 规则」类关键词时自动加挂微信通道回溯原文；数字密集命题走本地数据终端逐点对账。

CHANNEL ① · 中文主源

腾讯较真

对中文叙事、传闻、政策类命题覆盖深，作为查证第一源与第三源交叉标签的提供方。

jiaozhen_cli.sh --query "<claim>"
失败时 → 标注「较真不可用」，不重试轰炸
CHANNEL ② · 国际源补强

WebCite

英文命题与国际媒体立场参考，纯标准库客户端，Key 缺失时干净报错。

webcite_cli.sh "<claim>" --json
失败时 → exit=2 / 429 标注，不静默编造
CHANNEL ③ · 原文回溯

微信公众号搜索

平台规则与官方报告的原始出处常在公众号，搜狗微信免登录检索 Top10 结果。

weixin_search.sh "<query>"
反爬拦截时 → 标注「公众号通道未完成」
CHANNEL ④ · 数字对账

本地数据终端

报告关键数字逐点核对（营收、交付量、市占率等），会话内三档标注：准确 / 有出入 / 查不到。

02 · RULES

八条甄选规则，逐条可审计

规则不是建议，是协议：不满足条件的主张只能得到"不可靠"或"待查"标签。

RULE 1

双源验证

每条主张至少 2 个独立来源交叉；仅单源 = 不可靠，不晋级。

RULE 2

168 小时窗口

事件须落在报告日前 6 天内；过期事件是历史背景，不是新证据。

RULE 3

窗口覆盖报告日

扫描窗口终点必须 ≥ 报告日；过期扫描只标「扫描未完成」。

RULE 4

影响度评分

主题关联度 + 可核验锚点 + 事件烈度 + 验证等级，按分取 Top N。

RULE 5

第三源标签

存疑 / 印证 / 无覆盖 / 未完成超时——只标注，不阻断主流程。

RULE 6

失败降级

单源失败只降级标注，绝不编造、不静默丢弃；双源全挂 = 「命题待查」。

RULE 7

原文优先

公众号原文 > 权威转载 > 自媒体转述；仅有转载时标注「未回溯原文」。

RULE 8

版本差异检查

≥2 家转载内容不一致 → 自动触发原文回溯，报告输出「版本差异」提示。

03 · USAGE

统一入口，四步出报告

1
提交命题：bash scripts/verify.sh "中美关税协议已正式签署"
2
自动调度：中文 → 较真；英文 → WebCite；命中官方发布关键词 → 加挂微信通道；数字密集 → 数据终端逐点对账
3
双源交叉仲裁：一致则印证；冲突则并列两源、不强行调和；不可用则如实标注
4
输出结构化报告：Claim / Verdict / Analysis / Evidence / Source Quality / Correct Information / Sources
04 · RATINGS

六级评级量表

每个命题必得且只得一个评级；评级与证据清单一一对应，可逐条回溯。

✅ TRUE≥2 个独立可靠来源交叉印证
⚠️ MOSTLY TRUE核心事实准确，缺重要上下文
🔶 MIXED真假参半，或双源直接冲突
❌ MOSTLY FALSE误导性强，夹杂个别真元素
🚫 FALSE有官方/一手证据直接否定
❓ UNVERIFIABLE证据既不能确认也不能否定
免责声明 — 本工具用于信息核查与研究辅助，输出为信源结构化结果，不构成任何专业建议。查证遵循"查不到就标注"原则，请以官方披露为准。
